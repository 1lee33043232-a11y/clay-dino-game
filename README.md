# 말랑말랑 공룡 모험

파스텔 클레이모피즘 스타일의 공룡 달리기 게임입니다. 외부 이미지와 라이브러리가 필요 없는 단일 HTML 게임으로, `index.html`을 브라우저에서 열어 실행할 수 있습니다.

- 점프: 스페이스바, ↑ 또는 점프 버튼
- 엎드리기: ↓ 또는 엎드리기 버튼을 길게 누르기
- 각 단계에서 장애물 20개를 피하면 달성률 100%를 채우고 다음 단계로 이동합니다.
- 전체 게임에서 하트 3개를 제공합니다.
- 3단계를 모두 완료하면 폭죽과 빵빠레에 이어 경쾌한 축하 음악과 공룡 댄스 타임이 시작됩니다.
- 음악 끄기와 음량 조절을 지원하며, 완료 화면의 ‘춤 잠깐 쉬기’ 버튼으로 음악과 춤을 함께 멈출 수 있습니다.
- 선인장, 바위, 왕버섯, 새, 쌍둥이 선인장, AI 드론이 단계에 따라 등장합니다.
- 진행할수록 하늘색과 풍경이 변합니다.

## 검증

Node.js가 설치되어 있다면 `npm test`로 단계 진행, 장애물 회피, 하트, 최종 축하 효과와 재시작 동작을 확인할 수 있습니다.

## 배포

Vercel에서 Framework Preset을 Other로 선택합니다. 별도의 빌드나 패키지 설치가 필요하지 않으며 출력 디렉터리는 `.`입니다.
